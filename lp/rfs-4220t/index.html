Why the RFS-4220T

  • Wide, calibrated frequency coverage. 20 MHz to 20 GHz calibrated, settable up to 22 GHz, in one benchtop chassis, for lab, ATE, and field test work.
  • Multiple users, one instrument. Automatic network device discovery and toggleable multi-session control let more than one computer work with the same RFS-4220T.
  • Synchronized with the rest of the rack. An external 10 MHz reference input locks the RFS-4220T to a shared lab standard, and an external trigger input coordinates it with the rest of a test setup.
  • Operate however the bench requires. Full control from the integrated touchscreen, the physical front-panel buttons and rotary knob, or a remote computer application over LAN or USB, all kept in sync.

Where it's used

General RF and microwave laboratory testing, automated test environments, production verification, RF component characterization, local oscillator sourcing, antenna development, EMC and pre-compliance testing, wireless infrastructure development, educational labs, and aerospace and defense research.
